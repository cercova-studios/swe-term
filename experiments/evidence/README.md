# Curated experiment evidence

Each experiment may add a directory here only after reviewing raw runs for
secrets, proprietary data, incomplete terminal states, and misleading aggregate
metrics.

A publishable bundle should contain:

- the preregistered manifest and its digest;
- mechanically derived component metrics;
- selected redacted trajectories or stable artifact references;
- discordant-case analysis;
- a human-authored limitations section; and
- the accept, reject, or revise decision.

Evidence is not an architecture decision. Promotion still requires an explicit
human decision and the corresponding architecture/documentation update.
