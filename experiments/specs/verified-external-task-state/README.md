# Verified external task state

Status: draft. Compare a transcript with ordinary summarization against the same
transcript plus a compact read-only typed snapshot. The snapshot may update only
from attributable environmental observations and must retain source, revision,
freshness, and verification status.

Freeze the task sequence, change point, context-reset step, model identity, tool
schema, and budgets before preregistration. Measure stale action after the
change, redundant reads, time to rediscover, completion, tokens, and incorrect
snapshot promotions. This does not test a manager/executor/auditor topology.
