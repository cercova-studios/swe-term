# Protected-spine compaction

Status: draft. Compare ordinary free-form compaction with deterministic protected
spine extraction plus a summary of the unprotected remainder. Score the state
transition mechanically before using a model continuation as a secondary probe.

The protected treatment must preserve every active constraint, approval, error,
disproven hypothesis, dirty-file state, obligation, and artifact handle; it must
also remove explicitly superseded facts. Freeze corpus, summarizer/model, token
budget, and continuation task before preregistration.
