## Narrow claim

The abstract argues that structured rules with triggers, predicates, and
enforcement mechanisms can impose lightweight runtime constraints on agents.
It evaluates several domains, including code execution and autonomous driving.

## swe-term transfer

The paper validates the idea of runtime enforcement as a seam. A configurable
DSL and LLM-generated rules would add a second, unverified policy surface, so
they are specifically outside this experiment.

- [x] reference-only

It is useful contrast for explaining why the first implementation is closed and
table-driven rather than a general specification language.
