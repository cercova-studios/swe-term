# Paper note: LongHorizon-Harness

Final disposition: experiment-candidate

The abstract reframes long-horizon execution as task-state management: explicit
state is maintained outside context and updated only with independently verified
environmental facts. Its Manage-Execute-Audit loop is a confound for the local
question because it changes both state and agent topology.

Transfer: compare a transcript summary with a compact, read-only typed snapshot
on the same repository tasks after a forced context reset and a controlled
environmental change. Exclude the manager/executor/auditor split and do not use
the paper's aggregate benchmark numbers as a local target.
