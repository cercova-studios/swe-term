# Paper note: Structured Feedback Improves Repair in an LLM Agent Loop

Final disposition: experiment-candidate

The paper's abstract compares raw diagnostics against feedback identifying a
failure location, observed value, and admissible alternatives in 50 paired
TextWorld games. It reports that complete feedback improves terminal success,
while location plus observed value alone stays near raw diagnostics; prose and
keyed JSON perform similarly. The local hypothesis is therefore interface
information design, not JSON syntax.

Transfer: use the same repair fixtures, tool powers, call cap, and information
budget in both variants. Exclude additional semantic hints that cannot be
recovered from raw output. The paper's models, games, and headline scores do not
transfer automatically.

Sources: <https://huggingface.co/papers/2607.14167>,
<https://arxiv.org/abs/2607.14167>.
